## 🧩 About

**Deep Rock Galactic GUI** is a comprehensive mod menu for Deep Rock Galactic featuring overlay, ESP, loot tracker, config editor, and hotkey menu.

Based on popular mods like **DRG Mod Manager**, **Overlay Toolkit**, and **Config Editor**.

---

## ✨ Features

### 🎮 Core GUI
- Overlay — in-game menu with toggles for all features
- ESP — highlight enemies, minerals, and objectives through walls
- Loot Tracker — track all loot and resources in real-time
- Config Editor — edit game settings and keybinds easily
- Hotkey Menu — customizable hotkeys for quick access

### 🎨 Visuals & Unlocks
- Resource ESP — see all minerals and gold through terrain
- Enemy ESP — highlight bugs and health bars
- No Fog — remove environmental fog for better visibility
- Fullbright — brighten dark caves

### 🏋️ Utility & Training
- Infinite Ammo — never reload
- Infinite Health — god mode for testing
- Speed Hack — adjust movement speed
- Teleport — move to waypoints or teammates
